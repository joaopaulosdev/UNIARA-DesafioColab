# Desafio de Agendamento de Processos

Este repositório contém uma atividade prática sobre **escalonamento de processos em Sistemas Operacionais**, desenvolvida utilizando Python e Google Colab.

## Objetivo

Implementar e comparar diferentes algoritmos de escalonamento de CPU, observando como cada política organiza a execução dos processos.

## Algoritmos utilizados

- **FCFS (First Come, First Served):** executa os processos na ordem de chegada.
- **Round Robin:** distribui o tempo da CPU entre os processos utilizando um quantum definido.
- **SJF (Shortest Job First):** prioriza o processo pronto com o menor tempo de execução (burst).

## Desafio proposto

- Adicionar o processo P4, com chegada no instante 3 e burst 1.
- Comparar FCFS com Round Robin utilizando quantums 1, 2 e 4.
- Identificar qual política favorece o processo P4.
- Implementar o algoritmo SJF.
- Gerar gráficos de Gantt para representar a execução dos processos.
- Apresentar uma conclusão sobre os resultados.

## Tecnologias utilizadas

- Python
- Google Colab
- Jupyter Notebook
